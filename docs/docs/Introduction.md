# Introduction

![Hookup Guide Banner Image](/img/QwiicIMUBMI330-HGBanner.png)

The SparkFun 6DoF IMU - BMI330 (Qwiic) is a simple motion sensing breakout to measure and log movement and acceleration. It features the BMI330 6DoF IMU from . The BMI330 has a 3-axis accelerometer with four selectable ranges (&plusmn;2g, 4g, 8g and 16g) and a 3-axis gyroscope with five selectable measurement ranges (&plusmn;125&deg;/s, 250&deg;/s, 500&deg;/s and 1000&deg;/s). The BMI330 has an on-chip interrupt engine with smart motion features to allow the sensor to run in low power mode while still monitoring for motion events. The motion event features include motion detection, step detection, orientation and flat detection along with single, double and triple tap detection. It also has sensor time stamps to synchronize between the IMU and host device. The sensor also includes two programmable I/O pins for use with interrupt and synchronization events. This breakout routes these I/O pins to two plated-through hole pins. 

In order to follow along with this guide, you'll need the 6DoF IMU - BMI330 (Qwiic) breakout with the following items:

* [SparkFun RedBoard IoT - RP2350](https://www.sparkfun.com/catalog/product/view/id/17811/s/sparkfun-iot-redboard-rp2350/) (or other Arduino development board)
* [Qwiic Cable](https://www.sparkfun.com/flexible-qwiic-cable-100mm.html)
* [USB-C Cable](https://www.sparkfun.com/usb-c-to-usb-c-cable-1-meter-flexible-silicone.html)
